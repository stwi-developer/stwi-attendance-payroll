# STWI Attendance & Payroll V1.3

## Main fixes
- Uses Zoho `Total Hours` for STWI Leave / half-day classification and `Payable Hours` for stored worked hours.
- Correctly recognizes 06-Aug-2026 as STWI Leave (First Half), 17-Aug-2026 as half-day, and 27-Aug-2026 as full-day STWI Leave from the Zoho status + total-hours data.
- Uses source attendance time directly for late calculation.
- Normal login rule: after 09:30 is late; exactly 09:30 is not late.
- First-half STWI Leave uses 14:30 expected login; 06-Aug at 14:25 is not late.
- Generic ambiguous HALF_DAY does not automatically create a late mark; it remains a Manual Review case when appropriate.
- Added `GET /runs/:id/attendance-summary`.
- Run page now shows Leave & Late Summary before Manual Review, including leave dates, leave fractions and late-mark dates/minutes.
- All Run Detail actions now refresh run, attendance, summary, reviews and payroll data so the UI does not remain stale after upload/process/calculate/edit/delete/resolve.

## Important existing-run step
The database already contains attendance rows created by older versions. After installing this version, delete the existing August attendance file in the run, upload the original Zoho Excel again, then Process Attendance. Do not manually resolve false MISSING_CHECKIN records before re-importing.
