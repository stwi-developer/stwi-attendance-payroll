# STWI Attendance & Payroll V1.6 changes

1. Minimum work hours
   - Normal full working day: 8 hours.
   - Half-day working period: 4 hours.
   - A shortfall is converted into proportional leave (`missing hours / 8`), rounded to 2 decimals.
   - Weekends, holidays and full-day STWI Leave are exempt from the shortfall rule.

2. Payroll Review manual editing
   - Payroll Review now has an Edit action.
   - The editable panel covers the displayed payroll values, including working days, monthly payment, per-day value, security deposit amounts, leave/deduction amounts, penalty, P.Tax, payable amount, late marks, paid leave, double-deduction leave, dates, deposit and details.
   - Manual values are stored as payroll-result overrides and audited.

3. Multiple employees / ZIP upload
   - Monthly Run upload now accepts ZIP files containing `.xls`, `.xlsx` or `.csv` attendance files.
   - Each inner attendance workbook is extracted and processed independently by employee.
   - Employee View continues to keep uploaded employee data separated.
   - Payroll Review adds employee checkboxes, Select All/Clear and a Show Selected Only option, plus a total final-payable figure for the rows shown.

4. Existing confirmed payroll rules remain intact, including 31 calendar days for August, ₹200 P.Tax when gross salary is strictly greater than ₹12,000, 3 late marks = 1 leave, and security-deposit FULL/EMI handling.
